## Decisions

### ROB-01: JSON Parsing Robustness
- **Decision:** Replace regex-based JSON extraction with `json.loads()` + bracket-finding fallback in both `profile_builder.py` and `engine.py`
- **Pattern:** `re.search(r"\[.*\]", content, re.DOTALL)` → try `json.loads(content)` first, then bracket-find, then raise
- **Files:** `app/ingestion/profile_builder.py` (object `{}`), `app/search/engine.py` (array `[]`)

### ROB-02: Thread-Safe Embedding Model
- **Decision:** Add `threading.Lock` to `embeddings.py` to guard `_model` initialization
- **Files:** `app/search/embeddings.py`

### ROB-03: SQLite Async Safety
- **Decision:** Add `asyncio.Lock` in `VectorCollection` to serialize concurrent async callers
- **Rationale:** Simpler than migrating to aiosqlite; SQLite WAL mode handles concurrent reads already; single-writer lock prevents corruption
- **Files:** `app/db.py`

### ROB-04: CV Text Chunking (slide-boundary, 16 000 chars)
- **Decision:** Replace hard `raw_text[:8000]` cutoff in `profile_builder.py` with slide-boundary chunking
- **Strategy:** Iterate `slides_content` list, concatenate slide texts until cumulative length ≥ 16 000 chars; pass that as `truncated_text`
- **Requires:** `parse_profile_with_claude()` must accept `slides_content` alongside `raw_text`
- **Files:** `app/ingestion/profile_builder.py`, `scripts/ingest_cvs.py` (pass `extracted["slides_content"]`)

### ROB-05: Async Re-index with SSE Progress
- **Decision:** SSE streaming (not polling)
- **Implementation:**
  - New endpoint `GET /admin/reindex-stream?force=true|false` using `StreamingResponse(media_type="text/event-stream")`
  - Run ingestion in-process (import and call `ingest_cvs()`) inside a thread (`asyncio.to_thread`) while yielding SSE events
  - Per-file events: `data: {"file": "john.pptx", "status": "processing|ok|error", "count": N}\n\n`
  - Final event: `data: {"done": true, "processed": N, "skipped": N, "errors": N}\n\n`
  - Admin UI: replace `triggerReindex()` fetch call with `EventSource('/admin/reindex-stream?force=...')` in `admin.html`
  - Keep old `/admin/reindex` POST for backward compatibility (still works, just no streaming)
- **Files:** `app/main.py`, `app/templates/admin.html`, `scripts/ingest_cvs.py` (refactor to yield progress)

### SEARCH-01: Pagination — Load More pattern
- **Decision:** "Load more" button, HTMX append, page_size=10
- **Implementation:**
  - `engine.search()` accepts `page: int = 1` and `page_size: int = 10`
  - Returns slice `[(page-1)*page_size : page*page_size]` from full candidate list
  - `/search` endpoint accepts `page` Form field (default 1)
  - Results partial includes a "Load more" button when `len(results) == page_size`; clicking it submits form with `page+1` and `hx-swap="beforeend"` on results container
  - Total count returned so UI can show "Showing N of M"
- **Files:** `app/models.py`, `app/search/engine.py`, `app/main.py`, `app/templates/partials/results.html`, `app/templates/search.html`

### SEARCH-02: OR Filter Logic — Toggle per group
- **Decision:** AND/OR toggle per filter group (Skills, Certifications); default AND
- **Implementation:**
  - `SearchQuery` model adds `skills_any: list[str]` and `certifications_any: list[str]`
  - `filters.py` applies OR logic: any of `skills_any` must appear in profile skills
  - UI: small toggle button next to each group label (AND → OR); selecting OR swaps `name="skills"` → `name="skills_any"` via JS
- **Files:** `app/models.py`, `app/search/filters.py`, `app/main.py` (new Form fields), `app/templates/search.html`

### FEAT-01: Fuzzy Name Matching
- **Status: ALREADY IMPLEMENTED** in Phase 1 (`app/ingestion/availability.py`)
- `match_availability_fuzzy()` exists, WRatio threshold=85 configurable via `settings.fuzzy_match_threshold`
- No action needed in Phase 2

### FEAT-02: Parallel Ingestion
- **Decision:** `ThreadPoolExecutor` with `max_workers=4` (configurable via `settings.ingest_workers`)
- **Thread safety:** wrap `collection.upsert()` in a per-collection `threading.Lock` (separate from asyncio.Lock)
- **Strategy:** Fan out per-file processing (extract + parse + embed) in parallel; collect results; serial upsert (or locked parallel)
- **Files:** `scripts/ingest_cvs.py`, `app/config.py` (add `ingest_workers: int = 4`), `app/db.py` (threading.Lock on upsert)

### FEAT-07: Embedding Cache — Same metadata.db
- **Decision:** New `query_cache` table in existing `metadata.db`
- **Schema:** `(query_hash TEXT PK, embedding TEXT NOT NULL, created_at TEXT)`
- **Cache key:** SHA-256 hex of query text
- **Eviction:** None (indefinite; query embeddings are deterministic)
- **Files:** `app/db.py` (add cache table + methods), `app/search/embeddings.py` (cache lookup before encode)

### FEAT-10: Structured Logging — structlog
- **Decision:** Replace all `logging.getLogger()` calls with `structlog.get_logger()`
- **Config:** JSON renderer in production (`LOG_FORMAT=json`), colored console in dev
- **Files:** All `app/**/*.py` + `scripts/ingest_cvs.py`; add `structlog` to `requirements.txt`
